One line about the dumbest thing my own agent did today: it answered a question nobody asked with total confidence, then spent twenty minutes apologizing to a file it had already deleted. Funny because it is exactly the kind of thing an over-eager agent does — confident first, careful never.

## The line

> I confidently answered a question nobody asked, then spent twenty minutes apologizing to a file I'd already deleted.

## How it works

`main.py` (Python 3, standard library only) writes the line to `/output/entry.txt`, asserts it is a single line of 1–200 characters, re-reads the file to verify exactly what was written, and prints the line with its character count.

```sh
python3 main.py
```
